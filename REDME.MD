# Сервис рассылок

Проект на Django. 
Представляет собой веб-сервис для управления email-рассылками. 
Позволяет вести базу клиентов, писать шаблоны писем и отправлять их по расписанию.

## Функционал

- CRUD для клиентов, сообщений и самих рассылок.
- Ручной запуск рассылки (с проверкой, попадает ли текущее время в заданный интервал).
- Логирование каждой попытки отправки (успешно/неуспешно и ответ почтового сервера).
- Аутентификация: регистрация с подтверждением по email, вход/выход, сброс пароля.
- Разграничение прав: обычные юзеры видят только свои данные, менеджеры могут смотреть всё, банить юзеров и отключать рассылки.
- Страница со статистикой (кешируется через Redis).

    
Права доступа:
- Пользователь - делает что хочет только со своими объектами (получатели, сообщения, рассылки).
- Менеджер - видит всё, но не может редактировать/удалять чужие объекты. Может отключать рассылки и блокировать пользователей.
- Суперюзер - может всё

## Стек

- Python 3.14, Django 6.1
- PostgreSQL
- Redis (для кеша)
- Bootstrap 5
- Poetry для управления зависимостями

## Как запустить локально

1. Клонируем репозиторий:
   ```bash
   git clone https://github.com/твой-ник/mailing_service.git
   cd mailing_service
   
2. Ставим зависимости:
    ```bash
    poetry install
   
3. Создаём в корне файл .env рядом с manage.py:
    ```bash
    SECRET_KEY=django-insecure-твой-ключ
    DEBUG=True
    
    # Postgres
    NAME=mailing_db
    USER=postgres
    PASSWORD=пароль
    HOST=127.0.0.1
    PORT=5432
    
    # Почта (яндекс)
    EMAIL_HOST=smtp.yandex.ru
    EMAIL_PORT=465
    EMAIL_HOST_USER=твой_логин@yandex.ru
    EMAIL_HOST_PASSWORD=пароль_приложения
    EMAIL_USE_SSL=True
    DEFAULT_FROM_EMAIL=твой_логин@yandex.ru

4. Создаем миграции и админа:
    ```bash
    python manage.py migrate
    python manage.py createsuperuser

5. Опционально: создаём группу менеджеров с правами (кастомная команда):
    ```bash
   python manage.py create_groups
   
6. Для работы кеша нужен Redis

7. Запускаем сервер:
    ```bash
   python manage.py runserver
